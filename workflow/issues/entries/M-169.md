### M-169 · Attack watcher and HTTP result readers race on shared mutable outcome records · **MAJOR** · NEW · `CONSOLE`

**What:** The attack watcher mutates result fields outside the lock while HTTP readers/persistence marshal shared pointers; the real watcher/result read fixture triggers the Go race detector. Locking only writes or map lookup cannot protect references after unlock.

**Evidence:** intake/RPT-20260910-184000-console-result-race/VERIFICATION.md; assessments/20260910-readiness/fresh-console/LEAD-REVIEW-R1.md

**Required correction:** Publish immutable result snapshots or consistently synchronize copying and mutation across watcher updates, API readers and persistence; preserve causally scoped outcome fields and verify under race detector.
