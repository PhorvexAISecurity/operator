### M-76 · `do()` maps EVERY transport error to "stack unreachable" · **MAJOR** · 🟠 STATIC · `ACTUATION`
**What:** `errors.As(net.Error)` matches `*url.Error`, which wraps every client failure — refused, TLS, DNS, and crucially `context.DeadlineExceeded` from the tick deadline. A flush that the server already executed gets recorded as "no cache was flushed" — false forensics in the opposite direction from the one the code was hardened against.
**Fix:** explicit classification: ctx cancel/deadline → a distinct unknown-outcome sentinel; refused/DNS → unreachable; everything else → hard error.
*Sources: A-35, A-129.*
