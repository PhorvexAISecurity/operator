### M-85 · No recover anywhere in the actuate path — one handler panic kills the operator for every tenant · **HIGH** · 🟠 STATIC · `ACTUATION`
**What:** The feasibility layer deliberately recovers (fail-closed veto); the dispatch/tick path has none. A nil-deref in any handler (a live example: the kv-migrate multi-error deref) crashes the process mid-tick.
**Fix:** a fail-closed recover in dispatch mirroring the feasibility one.
