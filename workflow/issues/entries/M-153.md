### M-153 · Attack-vector steering: a forgeable event type string multiplies a cover weight ×3 and hard-sets the stage — an undocumented, attacker-reachable selection lever · **HIGH** · 🟠 STATIC · `BELIEF->KNOWLEDGE->CHOICE`
**What:** `a79c555` (PR #92, "steer the surgical actuator from a fired attack's vector", v0.4.64+, deployed 0.4.74) adds four SecurityEvent rule types `phorvex.attack.kv|guardrail|inflight|adapter` (`internal/model/types.go:251-256`). When a pod-targeting event of that type is active, (1) `stageFromEvent` returns `StagePersist` for it (`internal/killchain/hazard.go:201-205`) — the same weight as `Panic` — and (2) `ucw` recon multiplies the matching serving fact's weight by `vectorDominance = 3.0` (`internal/recon/ucw.go:176-184`, `:276`) so `kv-reset` / `guardrail-rotate` / `request-drain` outrank the cheaper `endpoint-rotate`. The trigger is `hasVectorEvent` (`:280-288`): **event `Type` string equality plus `TargetsPod`** — no source check, no signature, no rate limit. Combined with M-94 (any principal with `securityevents/create` is trusted), a forged event now chooses *which* actuator fires and raises the stage to persist; combined with M-19/M-27 it can do so every tick until the event ages out. It is default-on (no flag), and no design or coverage document describes it (M-123 widened). Legitimate use is the red-team console's `scenario_fire.go:74-92`, which is also its only emitter in-repo — i.e. the production brain carries a demo-steering channel on the live event bus. Not a duplicate of M-95 (one fact, adapter-specific) nor M-35 (hard-coded cover): this is a new, generalised, externally-triggered weight lever.
**Fix:** gate the vector types on an authenticated source (the M-94 fix), or restrict them to the redteam namespace/console identity; document the lever; record its firing in the decision trace (T0-C: a `steeredBy` field on the boosted fact — the ×3 is otherwise invisible in `finalWeight`).
*Sources: eleventh-pass window re-screen (`fb52e6c → 515c56a`), code at `515c56a`; derived, not live-tested (no forged `phorvex.attack.*` event has been fired — doing so is a one-line V-test for a later pass).*
