### M-167 · Shipped console storage configuration silently drops mutation and experiment records · **HIGH** · NEW · `CONSOLE`

**What:** The console resolves mutation audit, attack results, uptime and arm records beside the read-only mounted operator audit while its root filesystem is read-only. An actual policy edit still returns ok when the mutation file cannot be written; errors are discarded. Stdout retains one mutation line, so the claim is lost durable console artifacts, not zero evidence anywhere.

**Evidence:** intake/RPT-20260910-184000-console-state-persistence/VERIFICATION.md; assessments/20260910-readiness/fresh-console/LEAD-REVIEW-R1.md

**Required correction:** Provide an explicitly separate durable console state sink, preserve the operator decision audit read-only, validate storage at startup and expose write failures as unavailable/partial outcomes with retention/recovery tests. Do not enable audit truncation as a side effect.
