### M-135 · `EnsurePolicy` only runs on the actuation path — no self-heal while a tenant is idle or braked · **HIGH** · 🔴 LIVE · `CONTROL`
**What:** The AMTD CR (the tenant's Phoenix-side control object) is created/repaired only when the brain has a selected move to actuate. Live-observed 2026-08-21: with the namespace brake on (or zero selections), a deleted AMTD was never recreated across 15+ minutes of ticks, through mode and tenant changes; it reappeared within seconds of the brake coming off. So Phoenix-side management silently lapses for exactly the tenants that aren't currently firing — and nothing alerts on the drift.
**Fix:** run EnsurePolicy as a per-tenant periodic reconcile independent of actuation; add a status condition/metric for AMTD presence.
*Sources: second-pass live test V2 (2026-08-21).*
