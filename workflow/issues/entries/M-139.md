### M-139 · The economic thesis is measured for 1 of 15 generatable mutating actions — "coverage per dollar" where the dollar is an estimate · **HIGH (claim validation)** · 🟠 STATIC · `ECONOMICS`
**What:** The product thesis is *the cheapest surgical actuator that actually works*. The cover side has now been audited hard (T5 shows which credits are unsound). The cost side has not: the code's own registry labels every per-action flow cost `[ESTIMATE-UNVALIDATED]` except `kv-reset`, whose paired TTFT penalty was measured live (PHVX-9d, 20 paired samples on Qwen2.5-7B-AWQ/vLLM 0.7.3). All 16 actions share one [0,2] normalized scale that λ prices against — so the optimizer's "cheapest" comparisons are, today, comparisons against 15 unmeasured constants. This is bigger than M-108's constants debt: it is the existence proof's control variable, and nobody has framed it as a validation program with per-action measurement protocols (TTFT for cache moves, drain-time for request-drain, failover-gap for warm-swap, exec overhead for quarantine, …).
**Fix:** a cost-calibration campaign with one measured protocol per action family, replacing each `[ESTIMATE-UNVALIDATED]` with a measured value + confidence interval; re-run the actuator-selection benchmarks with measured costs to confirm the frontier survives.
**Sibling (2026-09-05, T1-D cycle): M-156** — the RLS learned path prices `Unknown`/`Draining` phases at the bias-only idle floor (0.15) while the heuristic path prices them 0.5/0.2. Same activation condition as this entry's "the day λ un-pins": the moment cost influence goes live, both the unmeasured-constants problem (here) and the phase-mispricing (M-156) matter immediately. File as one Math-ruling session.
