### M-80 · MIG `Available` is a wiring probe, not a capability probe · **MAJOR** · 🟠 STATIC · `CONTRACT`
**What:** It checks exec!=nil and a labeled pod Running — never executes even a read-only nvidia-smi. Every real incapacity (MIG disabled, agent without NVML, wrong container name) produces: relabel → drain → DELETE pod → discover the repartition can't run.
**Fix:** execute a non-mutating probe through the transport; cache briefly.
*Sources: A-128.*
