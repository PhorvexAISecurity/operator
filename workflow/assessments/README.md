# System assessments

Use `python3 workflow/tools/workflow.py guide assessment --show` to start a fresh
four-axis audit, master-register reconstruction or validation/recommendation investigation.
Copy `_template` into a dated directory; no assessment has been started by adding these templates.
Research records are manual. Canonical mutations use the existing intake, issue and campaign tools.
Historical methods are indexed in `../archive/audit-origins-20260909/README.md`.
