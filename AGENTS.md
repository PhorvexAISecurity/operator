# Repository agent entrypoint

For Phorvex issue intake, fixes, reviews, release reconciliation, or campaigns,
start at `workflow/AGENTS.md`. It routes to bounded, role-specific context.

Production code is outside `workflow/`. Preserve unrelated work. A request to
improve the harness authorizes harness code, documentation, and tests; it does
not start a product fix, deploy, or campaign.

Never add `Co-authored-by` trailers or similar AI-assistant attribution to Git
commits. Use the configured Git author and verify the message before pushing.
