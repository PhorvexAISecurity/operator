Section 01

Why greedy is exact on the facts we ship

Phorvex selects moves with a submodular greedy: each pick maximizes marginal·prov − λ·ECost. Greedy is provably optimal when the objective is modular — when no two pods can cover the same recon "fact".

The shipped standard-recon profile keys every fact by its owning pod — recon.Fact.Key() = "<ns>/<pod>|<kind>". So pod A's facts never collide with pod B's: covers are asset-disjoint, the set value is a plain sum, the objective is modular, and greedy equals the exact optimum. This isn't assumed — the engine brute-forces the exact optimum over the identical objective on every ablation (OptimalityOut) and self-checks disjointness.

Section 02

The boundary — where greedy would slip

A gap needs a shared fact. The hand-specified hub-spoke instance: three pool facts (weight 5) are each shared between a hub and one spoke; each spoke also has a private fact (weight 9). Budget B=2, λ=0.3, prov=1.

The load-bearing inequality

pool (5) < private (9) < 2·pool (10) — so two spokes (2 pools + 2 privates = 28) beat hub+spoke (3 pools + 1 private = 24), yet the hub standalone (15) outscores each spoke (14), so greedy grabs the hub first and is then locked out of the better two-spoke pair.

Section 03

The paired control — it's the sharing, not a bug

Re-key the three pools per pod (ns/hub|p0, ns/spoke-0|p0, …) so nothing is shared. Same topology, same B, same λ:

TestScenarioNonOptimal_DisjointControlIsExact
  PAIRED CONTROL (per-pod keys, disjoint): ratio=1.000000 — the gap vanishes; sharing is the cause
--- PASS

The gap appears the instant facts are shared and disappears the instant they aren't. That pair is the whole message: the greedy's exactness is a property of the fact model, and the shipped fact model keeps it exact.

Section 04

The gap, closed — greedy-then-swaps

A deterministic 1-exchange local search (localsearch.go), seeded from the base greedy: while a single add / drop / swap (one move per asset, ≤B total) strictly improves the objective, apply the best one. By construction it never underperforms greedy, is byte-identical on disjoint facts, and escapes the hub-spoke lock-in — from {hub, spoke-0} it swaps hub → spoke-1 onto the optimal {spoke-0, spoke-1}.

Honest scope

Greedy-then-swaps is a local search — it closes this gap and never regresses, but it is not a global solver for every submodular instance. A universal guarantee is the LP / MPC tier the note also names; swaps is the cheapest, ship-safe first rung. It is wired as a benchmark/opt-in optimizer — the shipped Decide is untouched (and on the disjoint facts it ships, promoting it would be a no-op).
