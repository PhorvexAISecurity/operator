# Archive

Historical documents kept for reference. Nothing builds from, tests or deploys
these files, and they are not maintained. They describe the system as it was
when written, before the monorepo restructuring.

- Repository-root documents (`PHORVEX_PRD.md`, `architecture.md`,
  `decisions.md`, `PROJECT-LOG.md`, the deployment guides and comparisons).
- `build/`: phase reports and attack catalogues from the first harness build.
- `phorvex/`: phase reports and decision records of the operator.
- `coversets/`: the cover-set decision cited by `docs/math-assurance`.

Raw evidence (workflow records, ticket reports, test-coverage runs, research
papers) is not here. It lives in
[PhorvexSecurity/operator@65af1c99](https://github.com/PhorvexSecurity/operator/tree/65af1c99265e29f72d6dba8f8216d5dfbe2fa9bb);
see `docs/provenance/` to map its commits.
