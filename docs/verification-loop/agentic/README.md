# Agentic verification workflow

Start with **[the complete portable V5 manual](WORKFLOW-V5.md)**. V5 incorporates
the boss's **Revision 4 DOCX and all seven revised workstreams**, including
existing-response proposals, conditional spec-only actuator design, separately
authorized engineering and reviewed normal-competition re-entry. Boss Revision 4
and workflow V4/V5 are separate version sequences.

**Current source-conformity status: independently accepted. Full physical-loop
completion: NOT_ESTABLISHED.** The [architecture/prompt review](REVIEW-ARCHITECTURE-V5.md)
and [requirements-map review](REVIEW-SOURCE-REQUIREMENTS-V5.md) bind exact source
bytes. They do not accept implementation, runtime admission, physical gates,
availability, deployment or a completed customer loop. The compiled manual is a
reading copy of those accepted components; its transform has separate review.

For a new run use [ARCHITECTURE-V5](ARCHITECTURE-V5.md),
[PROMPTS-V5](PROMPTS-V5.md) and [SOURCE-REQUIREMENTS-V5](SOURCE-REQUIREMENTS-V5.md).
Read [the revised-package change analysis](BOSS-REV4-CHANGE-ANALYSIS.md) for the
old/new source comparison. These documents preserve all seven metric fields,
G1/G2/G3, primary physical S1, current winner-conditioned re-attack, quarantine
refresh, registered coverage/minority duties, fresh independent reproduction
and safe cleanup. A design or engineering handoff is not a defended result.

The current owner preference is GPT-6.1 Sol for model workers. Separate actors
and specialties do not establish diverse underlying models. Model availability,
implemented tool descriptors, source/runtime pins, scope, budgets and independent
admission must be bound before physical work. Documentation adds no runtime
capability or execution authority. LangGraph implementation remains deferred.

## Source-local adapters versus physical proof

The [earlier protocol pilot](../../../build/test-harness/verification-workflow/README.md)
validates only its own handoff, local evidence and operation-admission contracts.
Newer source-local adapters are under
[verification-workflow/v4](../../../build/test-harness/verification-workflow/v4/).
Their directory name is an implementation revision, not current architecture
authority. Read exact independent source reviews and descriptors before use.

Local unit tests establish their stated structural behavior. They do not establish
an actual certificate, twin fidelity, physical G2, all seven measurements, a fresh
successful pair, a generic scheduler or a deployed LangGraph service. No test
count or generated catalogue count substitutes for completed original evidence.
